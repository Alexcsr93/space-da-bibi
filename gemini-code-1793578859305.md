# 🚀 Space da Bibi

Aplicativo PWA para Gestão Financeira e Controle de Rotina Diária da Bianca.

## 🛠️ Como subir para o GitHub e Testar

1. Crie um novo repositório no GitHub chamado `space-da-bibi`.
2. Adicione estes 4 arquivos (`index.html`, `manifest.json`, `sw.js`, `README.md`) na raiz do repositório.
3. No GitHub, vá em **Settings** > **Pages**.
4. Em **Branch**, selecione `main` (ou `master`) e clique em **Save**.
5. Aguarde 1 a 2 minutos e acesse o link gerado pelo GitHub Pages no seu celular!
