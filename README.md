# 🚀 Space da Bibi

Aplicativo PWA para Gestão Financeira, Controle de Gastos e Rotina Diária da Bianca.

## 🛠️ Como Atualizar no GitHub

1. Baixe o arquivo `space_da_bibi_completo.zip` enviado pelo assistente.
2. Extraia os 5 arquivos (`index.html`, `config.js`, `manifest.json`, `sw.js`, `README.md`).
3. Envie ou substitua estes 5 arquivos **DIRETO NA RAIZ** do seu repositório `space-da-bibi` no GitHub.
4. Aguarde de 1 a 2 minutos para o GitHub Pages compilar a nova versão.
5. No celular, abra em uma **Aba Anônima / Privada** para carregar direto do servidor e ignorar o cache antigo!
